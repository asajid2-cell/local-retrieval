Session history

  
Every chat this tab has hosted. Relaunch any of them, or file any into a collection so nothing this tab ran is ever lost.

  

  



  
Rename

  
Three independent names. The multiplex tab is the PC-hosted session (keeps running); the native name is the chat's own Claude/Codex title; the app name is this app's display override.

  
  
  
  
  
  
  
This tab isn’t linked to a chat, so only the multiplex tab name can change.

  



  
Add to collection

  
Adds this session’s chat to a deck. Works only while the desktop app is open — it owns your collections, so this can’t drift out of sync.
